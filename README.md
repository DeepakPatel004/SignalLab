# SignalLab

ITT 036 Digital Signal Encoder & Decoder, Autumn 2026. C++17 implementation.

Day 1 foundation. Generation and palindrome modules will be added incrementally.

## Build

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o signallab
```

Run `./signallab` on Linux/macOS or `.\signallab.exe` in Windows PowerShell.

## Planned stages

- Day 1: binary generation, longest palindrome, CLI and tests.
- Day 2: line coding and scrambling.
- Days 3-4: analog modulation, graphical output, decoding and submission report.
